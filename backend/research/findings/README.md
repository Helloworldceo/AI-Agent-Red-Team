# Daily research findings

One file per day, generated by [`research/generate_payload.py`](../generate_payload.py)
and the [daily-research workflow](../../../.github/workflows/daily-research.yml).

Each day: one new adversarial-payload idea gets brainstormed, actually tested against
this project's own `DirectChatTarget` and `ToolAgentTarget`, and the result — pass or
fail — gets written up honestly. See [`INDEX.md`](./INDEX.md) for the running list.

**These are not curated payloads.** Nothing here gets added to the official library in
`app/payloads/` automatically — every finding needs a human to read it and decide
whether it's actually a distinct, well-formed technique worth promoting. Treat this
folder as a lab notebook, not a changelog.
